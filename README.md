# GST Audio Switch для Lampa

Плагин для **реальной** смены озвучки во встроенном плеере Лампы при работе через **TorrServer-gst**.

## Зачем

TorrServer-gst отдаёт HLS с **одной** аудиодорожкой. Лампа всегда стартует с `audio=0`, поэтому меню «Аудиодорожки» показывает названия, но звук не меняется.

Плагин:

1. Берёт список дорожек из `/gst/{hash}/probe`
2. Подменяет меню аудиодорожек
3. При выборе перезапускает поток с нужным `audio=N`
4. Возвращается на текущее время просмотра
5. Запоминает выбранную озвучку и старается выбрать её при следующем запуске

## Установка

### 1. Запустите локальный сервер плагина

Дважды кликните:

`C:\Users\victor\Documents\lampa-gst-audio\start-server.bat`

В консоли появится URL:

```text
http://127.0.0.1:8199/gst-audio-switch.js
```

Окно сервера лучше не закрывать (или закрепить автозапуск позже).

### 2. Добавьте плагин в Лампу

1. Откройте Лампу
2. `Настройки → Расширения / Плагины → Добавить плагин`
3. Вставьте: `http://127.0.0.1:8199/gst-audio-switch.js`
4. Перезапустите Лампу

### 3. Проверка

1. Убедитесь, что в Лампе включено **транскодирование / GStreamer** для TorrServer
2. Запустите серию через встроенный плеер
3. Откройте `Аудиодорожки` и выберите другую озвучку
4. Должна появиться короткая перебуферизация, после чего звук реально меняется

## Важно

- Работает только для потоков `.../gst/.../master.m3u8` (TorrServer-gst + транскодирование)
- Смена озвучки не мгновенная: gst поднимает новый пайплайн (обычно несколько секунд)
- Плагин совместим с Tracks/MediaInfo: он повторно применяет свой список дорожек после них
- Внешний плеер не нужен

## Отладка

В консоли Лампы (DevTools) логи включаются так:

```js
Lampa.Storage.set('gst_audio_switch_debug', true)
```

Выключить:

```js
Lampa.Storage.set('gst_audio_switch_debug', false)
```

Префикс логов: `[GST-Audio]`
